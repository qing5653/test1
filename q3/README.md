# 问题3代码

`run_q3.py` 用于完成成都茶饮首店落地后的月度消费预测、DID 净效应估计，以及品牌集聚与夜间经济分析。

运行方式：

```bash
python3 q3/run_q3.py
```

默认读取 `data/q3/` 下的数据，并输出到 `q3/output/`：

- `q3_月度消费预测结果.csv`
- `q3_DID回归结果.csv`
- `q3_品牌集聚与夜间经济效应.csv`
- `q3_关键结论汇总.csv`
- `q3_结果摘要.md`
- `figures/q3_月度消费预测趋势.png`
- `figures/q3_DID处理组对照组趋势.png`
- `figures/q3_品牌集聚与夜间经济效应.png`

方法说明：

- 对带说明文字的 CSV 自动做清洗，过滤注释行和尾部备注。
- 使用带季节因子和节假日虚拟变量的 `SARIMAX` 模型生成基准消费预测。
- 在基准预测上叠加首店开业冲击、品牌集聚和夜间经济提升，形成首店情景预测。
- 使用 DID 回归估计首店开业带来的净消费拉动效应。
- 汇总首店对品牌集聚、夜间消费和社交热度的带动结果。
