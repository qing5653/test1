问题1代码

run_q1.py 用于完成问题1的成都商圈消费活力评价，默认读取：

  • data/问题一_成都商圈消费活力精修宽表.csv

运行方式：

python3 q1/run_q1.py

默认输出到 q1/output/：

  • q1_成都商圈消费活力评价结果.csv
  • q1_指标权重.csv
  • q1_标准化指标矩阵.csv
  • q1_结果摘要.md

评价思路：

  • 以 来源点位数、商场样本数、商圈成熟度指数、客流活跃度代理、类型潜力分、成本压力代理_租金 构成 6 指标体系。
  • 对正向与逆向指标分别做极差标准化。
  • 使用 AHP-熵权 组合权重，强调客流、成熟度和商圈层级，避免点位数量对结果的过度主导。
  • 输出综合得分、排名、商圈类别和空间分布特征。
