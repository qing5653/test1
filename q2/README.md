# 问题2代码

`run_q2.py` 用于完成成都茶饮首店选址优化，默认读取 `data/q2/` 下的候选区域与四类指标数据。

运行方式：

```bash
python3 q2/run_q2.py
```

默认输出到 `q2/output/`：

- `q2_成都候选区域宽表.csv`
- `q2_指标权重.csv`
- `q2_标准化指标矩阵.csv`
- `q2_成都首店选址排序结果.csv`
- `q2_Top3推荐区域.csv`
- `q2_分商圈代表推荐.csv`
- `q2_分项得分汇总表.csv`
- `q2_结果摘要.md`
- `figures/q2_候选区域综合排序.png`
- `figures/q2_Top3多维对比雷达图.png`
- `figures/q2_分商圈代表推荐对比.png`

方法说明：

- 对原始 CSV 中的说明行进行清洗，仅保留 `candidate_id` 以 `CD-C` 开头的有效候选区域。
- 合并交通、客群、租金、竞争四类指标，形成候选区域宽表。
- 针对 30-40 元客单价场景，额外构造“消费能力匹配度”指标，避免纯校园型区域被高估。
- 使用 `AHP-熵权` 组合赋权与 `TOPSIS` 进行排序。
- 同时输出“全局 Top3 推荐”和“分商圈代表推荐”，更适合论文中的分层决策表达。
